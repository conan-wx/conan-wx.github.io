# 伍星的工程手记

一本可以打开、翻阅的个人手记。包含个人介绍、求学历程、技能、10 个项目、2 段实习、7 项荣誉和记录页。电脑双页、手机单页，支持拖角、轻扫、键盘、目录与连续阅读。

站点：https://conan-wx.github.io/

这是公开阅读版本，不提供在线登录和编辑。更新内容后需重新构建并发布。

编辑源码及构建说明见 [website-source](website-source/README.md)。内容来自本人提供的资料，视觉与版式重新设计。交互参考 [StPageFlip](https://github.com/Nodlik/StPageFlip) 和 [The Book of Qbject](https://github.com/Qbject/the-book-of-qbject)。
